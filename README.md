# Samia Nakhoul | Portfolio

**Live site: https://samia-nakhoul.vercel.app**

Hi, I'm Samia, from Lima, Peru. I'm a two-time VALORANT Radiant, an in-game leader, a creator and a builder. I made this site for my application to Riot Games' **Community Manager Intern (Summer 2027)** role.

## What's on the site

- **Hero:** peak #165 on the LATAM leaderboard.
- **My story:** how a VALORANT lobby gave me a business partner, a team and a friend group.
- **The Climb:** an interactive chart of my peak rank in every act, from Silver 1 to Radiant.
- **Creator:** my TikTok, tournament footage, a post from X and clips from my stream.
- **Builder:** the startup I co-founded, and a week at Babson College.
- **Player Insight:** what I would bring to the team.
- **Contact:** how to reach me.

## For the curious: how it's built

- Next.js (App Router) and TypeScript
- Tailwind CSS
- A hand-built SVG chart, with no chart libraries
- Hosted on Vercel
- Respects `prefers-reduced-motion` and works on phones

To run it on your computer:

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
