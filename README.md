# Samia Nakhoul | Portfolio

Personal portfolio for my Riot Games Community Manager Intern (Summer 2027) application.

Two-time VALORANT Radiant, in-game leader, creator and builder from Lima, Peru.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Hand-built SVG chart, no chart libraries

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Notes

- Original design. Not affiliated with Riot Games. No Riot or VALORANT logos, agent art or official assets are used.
- Rank data comes from my own tracker.
